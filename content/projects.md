# Projects

## Water Tank Controller
ESP32, MQTT, Laravel, Livewire, Docker | [github.com/Schaulagain/water-tank-controller](https://github.com/Schaulagain/water-tank-controller)
* Fills the roof tank by itself and shows both tank levels live on my phone.
* The controller by the pump makes the decisions, so it keeps working when the WiFi or server is down.
* Stops the pump if the underground tank runs low or the pump runs too long, even after a power cut.

## Laravel Nepal Payments
Laravel, PHP, PHPUnit, GitHub Actions | [github.com/Schaulagain/laravel-nepal-payments](https://github.com/Schaulagain/laravel-nepal-payments)
* A demo store that takes payments through three Nepali gateways, modelled on what I built at work.
* A payment only counts once the gateway confirms it, and each order is invoiced exactly once.
* Tested, with the tests running on GitHub Actions.

## Homelab
Ubuntu Server, Docker, Pi-hole, Jellyfin, Tailscale | [github.com/Schaulagain/my-homelab](https://github.com/Schaulagain/my-homelab)
* An old laptop turned into a home server running ad blocking for the whole network and a media server.
* I reach it from outside over Tailscale, so no router ports are open.
